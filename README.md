# AI-Based Dynamic Traffic Signal Optimization

Research project: Deep Reinforcement Learning (DQN, PPO) for adaptive
traffic signal control in SUMO, using a Context-Aware Multi-Objective
Reward Function as the primary contribution, with planned extensions
for YOLO11m-based vehicle perception and simulated IoT sensing.
